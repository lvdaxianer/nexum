# ChatSurface 本地文本文件上下文设计

## 目标

让用户在聊天输入区选择一个 `.md` 或 `.txt` 文件，组件在浏览器本地读取全文，并在发送问题时把文件内容作为明确上下文附加到 Prompt。发送接口保持不变，失败时保留用户输入和附件以便重试。

## 方案

采用浏览器端读取方案：通过隐藏的 `input[type=file]` 提供选择入口，按文件名扩展名校验，只接受 Markdown 和纯文本；单文件限制为 512 KiB。读取成功后显示文件名和移除操作，发送成功后清理附件，发送失败则保留附件和问题。

最终 Prompt 使用固定分隔格式：

```text
用户问题

【文件：example.md】
<文件全文>
【文件结束】
```

不新增服务端上传接口，不发送本地文件路径或 `File` 对象，不支持二进制文件和多文件。

## 交互状态

- 未选择文件：保持现有纯文本发送路径。
- 读取中：展示读取状态，禁用发送和重复选择。
- 读取成功：展示文件名，允许移除。
- 类型/大小/读取失败：保留输入，显示可操作错误。
- 发送中：沿用现有发送 busy 状态，阻止重复提交。
- 发送失败：保留输入和附件；发送成功后才清理。

## 验证

- 纯函数测试覆盖扩展名、大小和 Prompt 包装。
- ChatSurface 测试覆盖文件读取成功、移除、失败保留和重复发送保护。
- 运行 ChatSurface focused test、包级 typecheck、相关 UI build 和仓库级 `bun run check`。
