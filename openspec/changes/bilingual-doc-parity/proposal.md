# Proposal

## Why

公开使用文档已经提供英文默认入口和中文镜像，但两种语言的内容深度不一致：部分英文文档被压缩，缺少中文版本中的章节、参数说明、模块边界、Session 操作和 API 细节。用户无法通过语言切换获得等价的学习路径。

## What Changes

- 以公开中文使用说明的完整信息架构为基准，补齐英文默认文档缺失的章节、表格、代码示例和参数解释。
- 保持英文与中文文档的章节顺序、代码块、公开 API 路径、参数名、事件名和模块入口一一对应，仅翻译说明文字。
- 统一根 README、文档中心、组合案例、能力说明、模块说明、UI/架构说明和 API 说明的双语导航与内容深度。
- 保留 OpenSpec、开发计划、审计记录、源码包 README 等内部资料在本次公开使用文档范围之外。

## Capabilities

### New Capabilities

无。本次只修正公开文档的双语内容一致性，不改变运行时、协议或 API 行为。

### Modified Capabilities

无。本次不修改协议、API 或产品能力要求。

## Impact

- 影响 `README*.md`、`docs/` 与 `docs/zh-CN/` 下的公开使用说明，以及 `apis/` 与 `apis/zh-CN/` 下的公开 API 文档。
- 需要重新校验文档目录、语言互链、代码入口、公开 API 名称、路由和参数的一致性。
