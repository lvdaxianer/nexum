# Proposal

## Why

README 和完整案例不需要重复展开 Session 的所有操作，但初学者必须知道应该从哪里查询 Session 的统一用法。需要把 README 和案例入口明确指向 Session 能力文档。

## What Changes

- 在 README 的完整案例说明中增加 Session 能力文档链接。
- 在完整案例中明确 Session 的列表、切换、历史、重命名、删除、取消和继续都集中在 Session 文档中。
- 不在 README 或案例中新增详细的操作代码。

## Capabilities

### New Capabilities

无。本次只调整文档导航。

### Modified Capabilities

无。本次不修改运行时能力或 API 要求。

## Impact

- 影响 `README.md` 和 `docs/examples/full-stack-chat.md` 的入口文案。
- 不修改源码、协议、依赖或发布产物。
