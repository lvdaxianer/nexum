# 修复文件上下文与用户消息回显

## Why

当前 ChatSurface 把浏览器读取的文件正文直接拼进 Prompt，但没有足够明确地告诉模型这是一份已经提供的本地文件内容，模型可能继续按文件名调用 `read` 或 `ls`，从而误报“找不到文件”。同时，用户消息在初始化状态回写时可能被覆盖，且回显完整文件正文会把用户真正的问题淹没。

本次修改继续采用浏览器本地读取和消息正文持久化，不新增文件上传接口或服务端文件存储。发送后，历史消息中的文件正文仍作为模型上下文保留；界面只回显用户问题和文件摘要。

## What Changes

## 范围

- 明确标记已读取的本地文件正文，要求模型直接使用正文，不按文件名查找。
- 初始化和状态回写不得覆盖已有用户消息。
- 从历史 Prompt 中解析用户问题和文件名，回显可读的用户问题与附件摘要。
- 补充单元测试和定向 UI 回归测试。

## 不在范围内

- 不保存浏览器本地文件路径。
- 不新增服务端文件上传、下载或附件 API。
- 不改变现有 Prompt API。
